### Исправленный баг обработки Retry

В браузере после каждого отказа была активна кнопка `Retry Failed batch`. Причина: `pythonWorkerSelectionRefresh` считала наличие любого завершённого batch достаточным условием доступности повтора, игнорируя `retryable` его элементов. Batch-обработчик также отправлял `retry_failed` каждому Job без предварительного отбора, в отличие от одиночного пути.

Исправление использует существующие Backend Jobs:

- Кнопка доступна только при наличии действительно повторяемого FAILED элемента.
- CHECKPOINT_REQUIRED, SESSION_EXPIRED, TWO_FACTOR_REQUIRED и FACEBOOK_TEMPORARILY_BLOCKED исключают повтор даже при устаревшем флаге retryable=true, включая ошибку дочерней task.
- Batch Retry сначала читает сохранённый status каждого Job и отправляет retry_failed только заданиям с повторяемым FAILED элементом. Он не открывает Facebook и не выполняет auth preflight.
- Прямой вызов одиночного Retry тоже прекращается для неповторяемого Job без Facebook preflight.
- Для Add RK checkpoint показывается отдельное сообщение о прекращении создания. Сохранённые Jobs остаются доступными для диагностики.
- Строка ошибки показывает точный backend Job ID и CREATE_NOT_SUBMITTED, если эта фаза присутствует в сохранённом FAILED шаге. Диагностика не выводит произвольные cookies, URL или raw result.
- Версия подключения Workspace JS повышена до v194, Docker проверяет новую версию.

Node-регрессия выполняет настоящие функции интерфейса с подменённым bridge: checkpoint-only batch, постоянная ошибка, смешанный batch, stale retryable=true, четыре terminal access code на Job/task, отсутствие preflight, защита прямого single Retry и ограниченный вывод диагностики. Локальный Node test и JS syntax check прошли. Полный CI и развертывание проверяются отдельно после публикации исправления.

### Что препятствует переходу к карте

На обоих проверенных профилях Facebook требует проверки аккаунта. Исправление UI не восстанавливает их Facebook-сессии и не проходит проверку за владельца. Рабочего нового РК в этой сессии нет. Связь FP с конкретным РК для рекламы не подтверждена. Нативная browser-привязка карты в текущем коде отсутствует; `payUnsettled.php` погашает задолженность и не является привязкой карты. Карточные данные не предоставлены, платежи и привязка карты не выполнялись. Увеличение числа профилей/попыток и изменение proxy/session для обхода проверки не выполнялись.
